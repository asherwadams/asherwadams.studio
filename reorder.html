How this works

  1. Drop all your portfolio photos here (any filenames, any order).
  2. Drag cards to reorder — the number in the corner shows position.
  3. Set the category for each photo using the dropdown.
  4. Click Export manifest.json and upload it to the portfolio/ folder on GitHub.
  5. Upload the photos themselves to the portfolio/ folder on GitHub (if not already there).

To reorder later: come back here, reload your photos, drag to new order, export again.
